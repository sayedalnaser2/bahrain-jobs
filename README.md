# Bahrain Jobs

A job board for Bahrain with search, filters and a job details popup.

- On GitHub Pages (static hosting) the site shows **sample listings**.
- Run `python server.py` locally with a free API key to show **live listings**.

## Run with live jobs
1. Get a free key from [Jooble](https://jooble.org/api/about) or JSearch on RapidAPI.
2. Copy `.env.example` to `.env` and paste the key.
3. Run `python server.py` and open http://localhost:8000.

`.env` is git-ignored so your key is never uploaded.
